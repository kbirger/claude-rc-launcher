# Svelte files

- Follow the best practices in the `svelte:svelte-core-bestpractices` skill for all Svelte components.
- Prefer bits-ui components, themed with shadcn and Tailwind, over custom UI patterns.
- Use the shadcn MCP for shadcn usage guidance.
- Keep complex logic out of components. Move it into view models and models.
